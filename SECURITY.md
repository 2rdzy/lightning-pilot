# Security policy

Lightning Pilot can move funds, so security reports are welcome and taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
**Security → Report a vulnerability** on this repository. You will get an answer as soon as possible; please allow
time for a fix before any public disclosure.

## Supported versions

There is no release yet. Once releases exist, only the latest release receives security fixes.
